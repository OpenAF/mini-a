# Wiki MCP starter

Copy the entire `wiki` directory and follow the [wiki MCP quickstart](../../docs/WIKI.md#serve-a-new-wiki-over-mcp). It includes setup for Mini-A, VS Code, Claude, Codex, and OpenCode.

Ask **“Where do I check a delayed dispatch?”** The [navigation guide](wiki/team-handbook-guide/SKILL.md) points to the team's terminology. The answer should cite the [scheduler runbook](wiki/operations/scheduler.md).

To make this your own, change the wiki's label in your launch command. Rename the guide folder and its `name` in `SKILL.md`, then update `wikiguide` to match. Describe when to use the guide in its `description`, replace the sample terminology with terms your team actually uses, and link to the pages where common questions are answered.
