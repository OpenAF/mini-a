# Navigate the Team Handbook

1. For unfamiliar terms, check [team terminology](references/terminology.md) and search using the handbook term.
2. For ambiguous results, consult [finding current procedures](references/workflows/finding-current-procedures.md).
3. Read and cite the operations page that answers the question.
